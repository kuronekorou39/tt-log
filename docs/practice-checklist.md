# 練習で使うときの手順

## 前日まで

- [ ] 最新の IPA を iPad と iPhone の両方に入れる（Sideloadly）
- [ ] iPad：役割「スコアボード」→ 選手を登録する
- [ ] iPhone：役割「カメラ」→ カメラ・マイク・ローカルネットワークを許可する
- [ ] 家の Wi-Fi で、2台がつながり、iPad で記録を始めると iPhone が録画を始めることを確かめる
- [ ] 充電器（できればモバイルバッテリー）、三脚、iPhone のホルダーを用意する

## 体育館で

1. iPhone のテザリング（インターネット共有）を ON にし、iPad をその Wi-Fi につなぐ
   - 体育館に Wi-Fi があれば、2台とも同じ Wi-Fi でもよい
2. iPhone を三脚に横向きで固定する。台の横、目線の高さ、3〜4m 離れた位置から、台と2人が入るようにする
   - 給電しながら使う。ケースは外す。直射日光を避ける
3. iPhone でアプリを開き「カメラ」画面にする。上に「〇〇 と接続中」と出るのを待つ
   - 出ないとき：「接続」から、iPad の記録前の画面に出ている IP アドレスを入れる
4. iPad を台の横（ネットの延長線上）に置き、「記録を始める」→ 2人を選ぶ → 最初のサーブと左側の人を選ぶ → 始める
   - この時点で iPhone が「第1ゲーム」の録画を始める
5. 「声 ON」にする。得点は「ひだり」「みぎ」（画面のどちら側の人の点か）、取り消しは「戻して」
6. ゲームが終わると iPad に「〇〇 勝ち」と出る。iPhone は3秒後に録画を止める
7. 「次のゲーム」と言う（またはボタン）と次のゲームが始まり、iPhone がまた録画を始める
8. 終わったら iPad の「終了」

## うまくいかないとき

- iPhone の録画が始まらない：iPhone の赤い丸ボタンで手動録画できる（手で止めると自動録画は OFF になる）
- iPhone が熱い：画面上部の「温度」が「高い」になったら日陰に移す。「危険」になると録画を自動で止める
- 声が効かない：画面の左右をタップしても点が入る。iPad の設定の「認識のモード」を変えてみる

## 帰ってから

- iPhone：「振り返り」で、ゲームごとの録画を得点の一覧から頭出しして見られる
- iPad：設定 →「音声ログを書き出す」で、聞き取りの記録を書き出して PC へ（`local/voicelog/` に置く）
