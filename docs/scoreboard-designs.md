# スコアボードのデザイン

画面右上のパレット、または「設定 → スコア表示 → デザイン」から変更する。
見本をタップした時点で反映される。初期値は「シンプル」。選択は端末内に保存し、アプリの再起動や新しい記録の開始後も維持する。

| デザイン | 表示の特徴 |
|---|---|
| シンプル | 従来の白／黒背景と丸みのある数字。端末のライト／ダーク設定に従う |
| フリップ | 黒いリング留めカード、黄色の得点、赤い獲得ゲーム数の札。めくり式得点板を意識した表示 |
| アリーナ | 暗い背景と7セグメント数字。選手ごとにミント／アンバーで色分け |
| フォーカス | 明るいブルー／サンドの面に濃い数字。サーブ側を濃紺の帯と太枠で示す |

サーブは得点と同じく、離れた場所から判断するための主要情報とする。全デザインで、サーブ側の下部にパネル幅いっぱいの不透明な帯と大きな「● サーブ」を表示し、そのパネル全体を太枠で囲む。シンプル／フリップは黄色、アリーナは選手のアクセント色、フォーカスは濃紺。色だけでなく、文字と大きな形の差で左右を見分けられるようにする。

サーブ帯はパネルの高さの約19%（36〜112pt）、太枠は3〜9ptを使う。非サーブ側にも帯と同じ高さの空間を確保し、交代しても数字の位置・大きさを変えない。ゲーム終了時は両側のサーブ表示を消し、勝った側の同じ場所に緑の「🏆 勝ち」の帯と太枠を出す。負けた側は少し暗くする。紙吹雪は約2.6秒で消える（「視差効果を減らす」の設定では出さない）。画面を覆うポップアップは出さないので、最後の点が間違いでもすぐ「戻す」で直せる。獲得ゲーム数は選手名の横にまとめる。

アリーナとフォーカスの色は選手に紐づき、左右を入れ替えると選手名・得点・獲得ゲーム数と一緒に移動する。得点の桁数は制限せず、長いデュースでも省略しない。

選択画面は本番と同じ表示部品を使用する。試合中はその試合のスコア、記録開始前や設定画面からはサンプルを表示する。見本のタップはデザインの選択だけを行う。

## 実装の分担

- `ScoreboardTheme.swift`：デザインの定義と色。保存先は `@AppStorage("scoreboard.theme")`。
- `ScoreboardDisplay.swift`：左右の選手表示と共通の得点ボタン。
- `ScoreboardDigits.swift`：カードと7セグメントの描画。画像・外部フォント・通信は不要。
- `ScoreboardDesignPicker.swift`：見本付きの選択画面とXcodeプレビュー。
- `ScoreboardView.swift`：試合データを表示部品に渡し、得点操作を既存モデルに戻す。

デザイン設定は `MatchConfig`、試合記録、カメラへの通信には含めない。画面の切り替えで `ScoreboardModel` を作り直さず、音声設定や接続にも変更を加えない。

## 端末での確認

対象は iPad Pro 10.5インチと iPhone 12 Pro の横画面。WindowsではSwiftUIのビルド・描画を確認できないため、iOS Buildと以下の確認が必要。

- [ ] 初回はシンプルになる。4種類を選択でき、チェック表示と実画面が一致する。
- [ ] アプリの終了・再起動後、記録の終了・再開後にも選択が維持される。他の端末の設定は変わらない。
- [ ] 試合中の切り替えで得点・ゲーム数・サーブ・左右・Undo／Redo履歴が変わらない。
- [ ] 各デザインで左右の面をタップすると、その位置の選手に1点だけ入る。音声入力、戻す、やり直しも同じ表示になる。
- [ ] 手動の左右入れ替え、次ゲーム開始、最終ゲーム5点で、選手名・色・得点・獲得ゲーム数・サーブ表示が一緒に移動する。
- [ ] サーブ交代で帯と太枠が同時に移り、点数の位置・サイズは動かない。デュース中の1点ごとの交代も確認する。
- [ ] ゲーム終了時は両側のサーブ帯・太枠が消える。「戻す」で再開したら、その時点のサーブ側に復帰する。
- [ ] ゲーム終了中は加点できず、次のゲームまたは記録終了に進める。戻す操作でゲーム中に戻れる。
- [ ] ゲーム終了で勝った側に「勝ち」の帯と紙吹雪が出て、得点は隠れない。下の帯に「次のゲーム」ボタンが出て、上の帯に「〇〇 勝ち　間違いなら「戻す」」と出る。
- [ ] 「戻す」で勝ちの帯と紙吹雪が消え、サーブ表示が戻る。
- [ ] 0、9→10、10対10、20点以上、3桁のスコア、2桁の獲得ゲーム数、長い選手名を表示できる。
- [ ] iPhoneでも得点・サーブ表示・ゲーム数が欠けず、上下の操作ボタンと終了表示が重ならない。
- [ ] ライト／ダーク設定の両方で選択画面とシンプルが読める。フォーカスは明るい表示、フリップ／アリーナは暗い表示を維持する。
- [ ] VoiceOverで選手名、得点、獲得ゲーム数、サーブ、各デザインの選択状態を読み上げる。
- [ ] 台から離れて、文字を読む前でも帯と太枠でサーブ側を即座に指せる。数字も読める。明暗の異なる体育館で比較する。

実物の得点板の参考：[バタフライ BTY・スコアボード](https://www.butterfly.co.jp/products/detail/77420.html)。製品画像やロゴは使用していない。
